# Whack-a-Mole

A 30 second arcade game. Moles pop out of nine holes and speed up as the clock runs down.

## Features

- 30 second rounds with a live score and countdown
- Moles appear faster as the round progresses
- Hit feedback and a small bounce animation
- Best score saved in local storage
- Touch and mouse friendly
- A How to play popup explains the rules

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.

## Files

```
index.html   markup
styles.css   styling
script.js    behaviour
```

## Tech

Plain HTML, CSS and JavaScript.
